# Drunk Swordfight (MG_DrunkSwordfight)

A tavern brawl: everyone gets a sword, 100 HP and one bottle of whiskey.
Last one standing wins.

## Controls

| Input | Action |
|---|---|
| WASD | Move (camera-relative) |
| Mouse | Wield the sword — the blade lags behind your aim like a heavy object; **tip speed deals damage**, so whip the mouse to swing |
| LMB | Stab lunge (big damage, telegraphs hard) |
| Mouse Y | Aim up/down (also aims the blade) |
| Q | Sip whiskey: +35 HP, +1 drunk level. **3 sips, one bottle, no refills.** |
| ESC | Release the mouse cursor (click to grab it again) |

## The whiskey trade-off

Each sip heals 35 HP but adds a drunk level (0-3). Drunk levels stack:

- camera wobble, roll and breathing get worse
- vignette + chromatic aberration + lens distortion ramp up
- your walk veers off course on the host
- the sword spring gets floppier and gains wobble torque — same mouse
  motion, lazier swing, less damage

So the bottle is a comeback mechanic that costs you control.

## Architecture (follows the harness rules)

- `DrunkSwordfightMinigame` — round flow: resets fighters, 3-2-1 countdown,
  elimination watch, winner announcement, placements to `MinigameBase`.
  Also owns the local atmosphere overrides (ambient, fog, foreign-light
  disabling, the post-processing volume) on every peer.
- `DrunkFightPlayer` (on the avatar prefab) — HP/sips/drunk in
  NetworkVariables, owner intent via ServerRpc (aim yaw, stab, sip), host
  applies damage/knockback/death. Dormant unless this scene is loaded.
- `SwordWielder` — the blade spring, simulated on every peer from the
  synced body yaw + aim pitch. Only the host judges hits (capsule sweeps
  between the last two blade-tip positions, damage scales with tip speed).
- `TavernArena` — builds the tavern deterministically in `Awake` on every
  peer: floor, bar, tables, stools, barrels, crates, lanterns.
- `DrunkFightCamera` / `FighterHud` / `OverheadHud` — owner camera + HUD,
  floating name/HP/sip/drunk bars for everyone.
- `ProceduralAudio` — all sounds synthesized at runtime (whoosh, clang,
  thud, glug, countdown beeps, fanfare). No audio files.

## Regenerating assets

Everything under `Assets/Resources/DrunkFight` (textures + materials), the
`MG_DrunkSwordfight` scene, and the character wiring in `PlayerAvatar.prefab`
is generated by `Assets/Editor/DrunkSwordfightSetup.cs`:

```
Unity.exe -batchmode -projectPath <repo> -executeMethod DrunkSwordfightSetup.RunAll -quit
```

Safe to re-run (idempotent). The setup also registers the scene in Build
Settings and appends it to the Hub's `MinigameManager.minigameScenes` list.

## Tests

`Assets/Tests/PlayMode/DrunkSwordfightSmokeTests.cs` boots a host, launches
the minigame through the real harness, and asserts the whole loop: gear
spawns, countdown unfreezes, sips heal and stack drunk (and the bottle
runs dry), damage kills, and the round resolves and unloads.

```
Unity.exe -batchmode -runTests -testPlatform PlayMode -projectPath <repo>
```
